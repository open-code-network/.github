## What is Open Code Network?

**Open Code Network (OCN)** is an independent, open-source software engineering foundry. We bypass basic tutorials and toy scripts to bring together top-tier student engineers and builders. We build, test, and maintain real production-grade software systems that solve institutional, civic, and operational challenges.

Rooted at our flagship hub in Kyambogo University and scaling outward via a structured **Hub-and-Spoke** network, OCN bridges the gap between academic theory and high-performance software engineering.

---

## Our Engineering Principles

*   **Production Over Theory:** Every repository under OCN represents real systems designed for live deployment—no throwaway code.
*   **Public-Good Open Source:** Transparent codebases tracked via GitHub Projects, enforced with strict peer-reviewed Pull Request standards.
*   **The Maintainer Pipeline:** Builders graduate into **Core Maintainers** who manage infrastructure, audit security, review cross-campus code, and lead engineering cycles.
*   **Rigorous QA & Testing:** Systems undergo cross-squad code reviews, blind usability tests, and structured bug bashes before touching production.

---

## Core Technology Ecosystem

Our squads build scalable, modern web architectures and distributed systems:
*   **Frontend:** React.js, Vite, Tailwind CSS, Modern JavaScript (ES6+).
*   **Backend & APIs:** Node.js, Express.js, Java (Spring Boot), Python (Django).
*   **Databases & Caching:** PostgreSQL, MongoDB, MySQL, Redis, Supabase.
*   **Infrastructure & DevOps:** Git CLI, Docker, Vercel, Render, Railway, Cloudflare DNS.

---

## The Hub-and-Spoke Architecture

1. **The Flagship Hub (Kyambogo University):** The central core where foundational architectures, core tooling, and initial engineering cohorts are forged.
2. **University Chapters:** Dedicated regional engineering squads deployed across other tertiary institutions in Uganda, operating under unified contribution guidelines.
